# Wire Bundle 0.2 — Blueprint и Material Editor

Редакторский C++ плагин для Blueprint (обычные K2-графы) и Material Editor.
Он собирает соединения в компактный горизонтальный пучок с помощью двух
штатных reroute-нод на каждый провод. Цвета, подсветка и рисование остаются
штатными; дополнительные типы нод или патч движка не нужны.

## Установка

Закройте редактор. Скопируйте папку `WireBundle` в `<ВашПроект>/Plugins/`.
Для установки исходников потребуется C++ toolchain Unreal. Откройте проект
и согласитесь на сборку модуля. Включите **Wire Bundle** в Edit → Plugins,
если он ещё не включён, и перезапустите редактор.

Для установки без компиляции используйте собранный пакет именно для своей
версии UE из `dist`: распакуйте `WireBundle` в `<ВашПроект>/Plugins/`.

## Использование

### Жест поперёк проводов

1. Зажмите **Ctrl+Alt** и левую кнопку мыши в графе.
2. Протяните прямую линию через нужные провода. Предварительное выделение
   нод не требуется. Пересечённые провода подсвечиваются голубым, рядом с
   курсором показано их количество. Зелёная линия означает минимум два провода.
3. Отпустите левую кнопку внутри того же графа. Пучок появится в середине линии.
4. **Esc** или другая кнопка мыши отменяет жест. Отпускание за пределами
   исходного графа тоже отменяет действие. Короткий клик ничего не меняет.

Пока жест активен, колесо мыши не меняет масштаб, чтобы подсветка соответствовала
снимку геометрии проводов. При потере активности приложения жест отменяется.
Выбор работает по отображаемым пинам и штатным сплайнам Blueprint/материалов,
включая обратные изгибы reroute-нод. Скрытые пины и отрисовка других плагинов
могут отличаться; перед отпусканием ориентируйтесь на голубую подсветку.

### Команда для выделенных нод

1. Выделите ноды, между которыми проходят нужные провода. Обе конечные ноды
   каждого провода должны быть выделены; нужно минимум два соединения.
2. Поставьте курсор в свободном месте графа, где должен оказаться центр пучка.
3. Нажмите **Ctrl+Alt+B** (физическая клавиша B).
4. Созданные reroute-ноды выделятся. Перетаскивайте их вместе или выделите
   отдельный столбец, чтобы изменить форму пучка.
5. **Ctrl+Z** отменяет создание целиком; **Ctrl+Y** возвращает его.
6. Сохраните Blueprint или материал обычным способом.

Пучок имеет длину 160 единиц графа и расстояние между проводами 12 единиц.
Для изменения положения концов используйте штатное выделение reroute-нод.
После удаления плагина сохранённые reroute-ноды продолжают работать.

## Ограничения

Это прототип на нативных reroute-нодах, а не полная копия инструмента из видео.
Пока нет отдельной ручки шины, распознавания ранее созданных пучков или
автоматического обхода других нод. Повторная команда
добавляет новые reroute-ноды. Для отмены используйте Undo; при обычном удалении
reroute-нод может потребоваться восстановить соединения вручную.
Команда отключена для read-only графов и во время PIE. Специализированные
графы (Niagara, AnimGraph, Control Rig и другие) не обрабатываются.

Материалы обслуживаются через штатную операцию вставки reroute в открытом
Material Editor, включая его обновление после изменения графа. Это может
вызывать перекомпиляцию материала при вставке каждой ноды на больших графах.

## Проверка

Версия 0.2, 26 октября 2026: сборки Win64 для UE 5.5.4 и UE 5.8.0.
Автоматические проверки включают:

- `WireBundle.Blueprint.BundleUndoRedo`: соединения, выделение, Undo и Redo.
- `WireBundle.Blueprint.GestureScopeUndo`: выбор только пересечённых проводов,
  работа без выделения нод, фильтрация дубликатов/невалидных ссылок и read-only.
- `WireBundle.Gesture.Intersections`: пересечение прямых и ломаных, касания,
  допуск, обратное направление, короткий клик, несколько пересечений одного провода.
- `WireBundle.Material.BundleUndoRedo`: открытие временного материала в Material
  Editor, вставка пучка, проверка исходных назначений и Undo/Redo.

Для полного набора тестов в UE 5.5 используйте обычный запуск с рендерингом:
NullRHI в этой версии вызывает ошибку движка при закрытии временного окна
Material Editor. В UE 5.8 эти тесты работают и с NullRHI.
Ввод мышью и отображение предпросмотра в пользовательском проекте,
сохранение/повторное открытие ассетов ещё не проверены вручную.

В модуле есть тест `WireBundle.Blueprint.BundleUndoRedo`: проверяет создание
четырёх reroute-нод для двух соединений, сохранение пути к исходным входам,
выделение, Undo и Redo. Его можно запустить в Session Frontend → Automation.
Интерактивную проверку в обоих редакторах проводите на копии ассета: создайте
два соединения, примените команду, сдвиньте reroute-ноды, проверьте Undo/Redo,
сохранение и повторное открытие, затем скомпилируйте Blueprint/материал.
