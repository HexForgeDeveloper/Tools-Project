# Wire Bundle 0.8

Плагин редактора для объединения соединений в Blueprint и Material Graph с помощью стандартных reroute-узлов Unreal Engine.

## Команды

- При удержании Ctrl+Alt+ЛКМ колесо вниз уменьшает число колонок reroute-узлов, вверх увеличивает: 1, 2, 3 и далее. Предпросмотр обновляется сразу, отпускание ЛКМ создаёт выбранную форму. Вне жеста колесо работает как обычно.
- Ctrl+Alt+B — создать связку между выделенными соединёнными узлами; на узле зарегистрированной связки — выделить связку целиком.
- Ctrl+Alt+A — зарегистрировать старые цепочки. Выделите только reroute-узлы как минимум двух полных цепочек.
- Ctrl+Alt+стрелки — переместить выделенные reroute-узлы; Shift ускоряет движение.
- Правый клик по узлу → Wire Bundle: создать связку / зарегистрировать цепочки, а на зарегистрированном reroute — выделить всю связку / Unbundle wires.

Unbundle wires восстанавливает прямые соединения и удаляет только reroute-узлы этой связки. Посторонние соединения сохраняются. Разбор, создание и регистрация поддерживают Undo/Redo. Если цепочка была повреждена или получила дополнительные ответвления, разбор недоступен. Команды повторно проверяют граф при выполнении.

Во время жеста Ctrl+Alt+ЛКМ отображается будущий маршрут и точки вставки reroute-узлов (ромбы). Режим по умолчанию задаётся в Movement → Layout → Reroute Columns. Максимум при создании задаёт Max Reroute Columns (по умолчанию 8, до 32); переключение колесом включается в Gesture → Input → Wheel Changes Columns. Ширина, интервал, смещение и привязка к сетке рассчитываются тем же планировщиком, что и при создании. Цвет, толщина и видимость предпросмотра доступны в Appearance → Route Preview. Прорисовка кривых служит ориентиром; окончательные сплайны рисует Unreal.

Настройки находятся в Editor Preferences → Plugins → Wire Bundle. Пользовательские Data Assets не требуются.

## Изменение формы мышью

Выделите один или несколько обычных reroute-узлов в Blueprint или материале. Ручки появляются прямо для выделения, независимо от того, кем созданы узлы; регистрация через плагин не требуется. Для уже зарегистрированной связки по-прежнему достаточно выбрать один её узел, чтобы редактировать связку целиком.

- Центральная ручка со стрелками перемещает всю связку.
- Боковые ромбы изменяют ширину связки; промежуточные узлы перемещаются пропорционально, сохраняя форму. Ручки ширины скрыты, если у группы нет горизонтального размера.
- Нижний ромб изменяет расстояние между отдельными выбранными цепочками или несоединёнными узлами относительно центра. Для единственной цепочки он скрыт.

Перетаскивайте ручку левой кнопкой без модификаторов. До отпускания показывается только предпросмотр; граф не меняется. Отпускание внутри исходного графа применяет результат одной операцией Undo. Esc (или настроенная клавиша отмены), потеря фокуса и отпускание снаружи отменяют действие. Обычное перетаскивание стандартных узлов остаётся доступным.

Настройки Movement → Mouse Editing включают ручки и ограничение оси движения. Используются общие настройки привязки к сетке. Цвет и размер ручек задаются в Appearance → Shape Handles. Если топология или позиции изменились во время перетаскивания, результат не применяется.

Ручки поддерживают обычные и зарегистрированные reroute-узлы, длинные цепочки и разное число узлов на разных проводах. Соединения и внутренние изгибы сохраняются. Для обычного выделения не создаётся запись связки: редактируются только выбранные узлы. Регистрация через Ctrl+Alt+A нужна лишь для постоянного распознавания и команды Unbundle, а не для появления ручек. Ограничение числа колонок при создании не ограничивает редактирование уже существующих цепочек.

## Модули

- WireBundle: команды, ввод и отрисовка, планирование маршрута, настройки, хранение и проверка связок.
- WireBundleTests: автоматические тесты. Зависимость направлена на WireBundle; основной модуль не зависит от тестов.

Публичные заголовки основного модуля предоставляют интерфейсы командам и тестам. Запуск модуля отделён от команд и подключения контекстного меню.

## Поддержка

Сохранение и разбор зарегистрированных связок поддерживаются в Blueprint и основных графах материалов. Material Functions и composite-графы пока не поддерживают хранение связок. Их стандартные reroute-узлы остаются редактируемыми средствами Unreal.

Далее по плану: обход препятствий и дальнейшее расширение редактирования формы.

## Проверка

18 автоматических тестов: создание, область жеста, координаты окна, настройки и движение, план маршрута, регистрация, сохранение/загрузка/дублирование, разбор и изменение формы с Undo/Redo. Тесты находятся в категории WireBundle окна Automation. Разбор материалов дополнительно проверяется после Apply и повторного открытия ассета.

Для изменения структуры модулей закрывайте Unreal Editor и собирайте ToolsProjectEditor. Live Coding не заменяет полную сборку при добавлении модуля.

Переключение колесом, поведение ручек при реальном вводе мышью и внешний вид требуют ручной проверки в редакторе.
